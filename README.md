# ChangeGuard

**Agentic infrastructure change review that predicts deployment risks before they reach production.**

ChangeGuard reviews a real GitHub pull request, extracts infrastructure/configuration changes, applies deterministic safety rules, optionally asks an LLM risk agent for additional hypotheses, verifies every AI claim against exact diff evidence, and produces an evidence-backed **PASS / WARN / BLOCK** decision.

> The model is allowed to propose risks. It is not allowed to invent proof.

Built for the **micro1 Agentic Workflows Hackathon 2026**.

## Why this exists

Infrastructure reviews are difficult because a small YAML, Terraform, Dockerfile, or CI change can have an outsized production impact. A generic LLM review can be useful, but it can also confidently infer context that is not present in the pull request.

ChangeGuard separates **hypothesis generation** from **evidence verification**:

```text
GitHub PR
   ↓
GitHub Collector
   ↓
Change Parser
   ↓
Deterministic Risk Rules
   ↓
Risk Agent (optional LLM)
   ↓
Evidence Verifier
   ↓
PASS / WARN / BLOCK
   ↓
SQLite-backed history, reports and benchmark results
```

## Implemented

- Real GitHub PR ingestion (public repositories without a token; private repositories with a PAT).
- Changed-file and patch collection through the GitHub API.
- Deterministic checks for Kubernetes, Terraform, Dockerfiles and GitHub Actions.
- OpenAI-compatible LLM provider configuration.
- Agent risk hypotheses with strict structured JSON output.
- Verification of LLM claims against literal evidence in the referenced diff.
- Rejected-claim tracking instead of silently accepting hallucinated evidence.
- Evidence-backed PASS / WARN / BLOCK decisions.
- Analysis trajectories with tool/action stages.
- SQLite persistence for analyses, settings and benchmark runs.
- Real Dashboard, Analyses history, Reports, Benchmarks and Settings views.
- Markdown report export.

python -m pip install --upgrade pip

## GitHub integration

Public PRs work without credentials. For private repositories or higher rate limits, configure a GitHub personal access token from **Settings → GitHub**, or set:

```env
CHANGEGUARD_GITHUB_TOKEN=github_pat_xxx
```

Credentials are never included in reports. The current hackathon/local build stores settings in the local SQLite database; see [SECURITY.md](SECURITY.md) for the production-hardening note.

## LLM provider

The LLM layer is optional. Without it, ChangeGuard runs in deterministic mode. With an OpenAI-compatible provider configured, the workflow adds a Risk Agent and independent evidence verification.

Default API base:

```text
https://api.openai.com/v1
```

Provider settings are configured in the UI. The final benchmark should use a fixed model and temperature for both baseline and agentic runs.

## Safety model

ChangeGuard is a **review system**, not an autonomous deployment executor. It does not apply Terraform, deploy Kubernetes resources, or modify production infrastructure. GitHub review publication is an explicit user action.

AI-generated blocking claims must be backed by verifiable evidence. Unsupported claims are retained as rejected claims for auditability.
